# CyberSec iOS 27 Toolkit

Professional penetration testing and device management utility featuring iOS 27 Liquid Glass UI design.

## Features:
- 30/70 Split Layout with Device Mockup and Telemetry (SN, masked iCloud, iOS 27 info).
- Screen Time Removal (OpenMenuX style).
- Account Hiding & Screen Time Bypass combo.
- OTA Update Blocking & Fake Reset implementation.

## Usage:
```bash
pip install -r requirements.txt
python main.py
```
